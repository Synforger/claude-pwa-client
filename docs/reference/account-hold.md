# 口座の止める線

口座の 7 日の使用率か 5 時間の使用率が、操作者が決めた線に届いたら、その口座で動くタブを区切りで止める仕組みです。上限に
当たる前に止めて、残りの枠を取っておくために使います。止めたタブは、**操作者が画面から続けるまで止まったまま**
です。0:00 になっても、使用率が下がっても、自動では再開しません。
ただし、[口座の逃げ先](account-fallback.md) でこの口座へ移ってきたタブだけは、**本来の口座が線を下回ったら、本来の口座へ戻して
自動で続けます** ([本来の口座が空いたら](#本来の口座が空いたら))。

[口座の逃げ先](account-fallback.md) は、タブを別の口座へ移して動かし続けます。止める線は、タブを止めます。
1 つの口座はどちらか一方です。

既定では何もしません。止めたい口座にだけ、設定を足します。

## 設定

`config.json` の、止めたい口座に `hold` を足します。

```json
"accounts": {
  "personal": {
    "display_name": "Personal",
    "env": {},
    "hold": {
      "five_hour_at_pct": 95,
      "seven_day_at_pct": { "mon": 70, "tue": 76, "wed": 82, "thu": 88, "fri": 94, "sat": 100, "sun": 70 }
    }
  }
}
```

| 項目 | 意味 |
|---|---|
| `five_hour_at_pct` | 5 時間の窓の止める線 (任意)。1 以上 100 以下の整数。既定は無く、書かなければ 5 時間の窓では止めない |
| `seven_day_at_pct` | 7 日の窓の止める線を、曜日ごとに決める表 (任意)。曜日の名前から 1 以上 100 以下の整数への対応 |

`five_hour_at_pct` と `seven_day_at_pct` のどちらか一方は書きます。

- 曜日の名前は `mon` `tue` `wed` `thu` `fri` `sat` `sun` です。**書いていない曜日は、止めません**
- 曜日は backend が動く機械の地方時で決め、0:00 に切り替わります
- 5 時間の窓の線は曜日では変わりません。`five_hour_at_pct` を書かなければ、5 時間の窓は見ません
- 次の `hold` は無いものとして扱い、起動時に log へ警告を 1 行出します
  - `hold` が表でない、`five_hour_at_pct` も `seven_day_at_pct` も無い
  - `five_hour_at_pct` が 1〜100 の整数でない
  - `seven_day_at_pct` が表でない、曜日の名前でない項目がある、値が 1〜100 の整数でない
  - 口座が `fallback` を持っている (逃げ先へ移す口座に、止める線は置けません。`fallback` は残ります)
- 設定は、画面の「設定」から変えられます ([設定の画面](settings-screen.md))。変えた値は、次の見回りから効きます。
  `config.json` を手で書き換えた時は、backend を再起動してください
- 見回りは、[自動の入れ替え](rollover.md) と同じ 60 秒ごとです

## 止める条件

次の**全部**がそろったタブを止めます。

| 条件 | 内容 |
|---|---|
| タブが動いている口座の使用率が、線以上 | その口座の最新の使用率の行 (`rate-limits.jsonl`) で、7 日の使用率が今日の曜日の線以上か、5 時間の使用率が `five_hour_at_pct` 以上のどちらかで、その窓の `*_resets_at` をまだ過ぎていない。線の無い窓は見ない。口座の行が 1 つも無い時は何も言えないので止めない |
| 口座が、そのタブの今動いている口座 | 逃げ先の口座で動いているタブも、その口座の線で止めます。ただし、本来の口座が線に届いていない間は、止めずに本来の口座へ戻します (下) |
| タブが固定されていない | 「口座を固定」したタブは止めません ([口座の逃げ先](account-fallback.md#口座を固定)) |
| タブが眠っていない | 眠っているタブは、止める物がありません |
| タブが止めても壊れない区切りにある | [眠り](sleep.md) の判定を「親が手で眠らせる時」の形で使う |

区切りの判定は、[口座の逃げ先](account-fallback.md#移す条件) と同じです。当たらないタブは止めず、当たらなく
なった次の回に止めます。上限で止まったタブは、止まったこと自体を区切りとして止めます。

### 逃げ先で動いているタブ

[口座の逃げ先](account-fallback.md) でこの口座へ移ったタブは、この口座が線に届いても、**本来の口座が線に届いていなければ止めません。**
逃げ先の側が、次の区切りでそのタブを本来の口座へ戻します ([逃げ先が線に届いた時](account-fallback.md#逃げ先が線に届いた時))。
本来の口座も線に届いている時と、本来の口座の使用率が分からない時は、このタブも止めます。仕事が止まるのは、本来の口座もこの口座も
線に届いている時だけです。

## 止め方

区切りにあるタブを、[眠り](sleep.md) と同じ終わらせ方で眠らせます。会話は、同じ会話のまま起こせます。そして、
タブの定義 (`session_meta.json`) の `held_at` に、止めた時刻 (epoch 秒) を残します。backend を再起動しても残ります。

```
account hold: held session=ses_0123456789ab account=personal stopped_by_limit=False
```

区切りに当たらなかった理由は、同じ理由が続いている間は log に 1 回だけ出ます。

```
account hold: waits session=ses_0123456789ab account=personal reasons=turn_open
```

### 答え続けているタブ

返事を作り続けているタブ (`turn_open`) は、いつまでも区切りに来ません。**区切りに来てくれるよう、client が 1 回だけ
頼みます。** 頼む条件は [口座の逃げ先](account-fallback.md#答え続けているタブ) と同じで、頼んだ時刻はタブの定義の
`hold_asked_at` に残します (backend を再起動しても 2 通目は送りません。使用率が線を下回った時、タブを止めた時に消します)。
連絡は、client の連絡の 1 行目で始まります。

```
Sent by the client (the operator did not type this):
<account-hold phase="stop" account="personal">
Personal の口座の使用量が止める線を超えたので、このタブを止めます。今の作業を区切りの良い所まで進めて、この返事を終えてください。続きは、操作者が画面から続けた時に頼む連絡が届きます
</account-hold>
```

頼んだタブが区切りに来たら、次の見回りが止めます。頼んでから 10 分たっても区切りに来ないタブには、もう送らず、
log に 1 行だけ出します。

```
account hold: asked to stop session=ses_0123456789ab account=personal
account hold: no break after asking to stop session=ses_0123456789ab account=personal waited_sec=612
```

## 止まっている間

- 止まったタブにも、別のタブからの連絡は今までどおり届きます。届けば、タブは同じ会話のまま起きて、`held_at` が消えます
  (log: `account hold: released ... woken=1`)。使用率がまだ線以上なら、そのタブは次の区切りでまた止まります
- 止まっているタブの数は、設定の画面の口座の欄に出ます

## 続ける

続けるのは、操作者です。設定の画面の口座の欄の「全部続ける」を押すと、その口座の `held_at` が付いたタブ全部に、
続けての連絡を送って起こし、`held_at` を消します。口は `POST /accounts/{口座}/continue` です。

```
Sent by the client (the operator did not type this):
<account-hold phase="continue" account="personal">
止めていたタブを続けます。止める前の作業を続けてください
</account-hold>
```

```
account hold: continued session=ses_0123456789ab account=personal
```

- 使用率がまだ線 (7 日は今日の線、5 時間は `five_hour_at_pct`) 以上なら、`409` (`still_at_line`) で断ります。線を上げるか、使用率が戻ってから押してください
- 連絡が届かなかった (Claude を起こせない・受け取らない) タブは、`held_at` を残し、答えの `failed` に入れます。もう一度
  押すと、そのタブだけにもう一度送ります
- `hold` を設定から消した口座でも、止まったタブは続けられます (線が無いので、`409` にはなりません)

## 本来の口座が空いたら

[口座の逃げ先](account-fallback.md) でこの口座へ移ってきたタブを止めたのは、「本来の口座もこの口座も線に届いている」ことでした
([逃げ先で動いているタブ](#逃げ先で動いているタブ))。その後に本来の口座だけが空いたら、止まったタブは**本来の口座へ戻して、
自動で続けます。** この口座は使いません。この口座の止める線の目的 (線を超えて使い続けない) とは食い違いません。

続ける条件は、次の**全部**です。

| 条件 | 内容 |
|---|---|
| タブが止まっている | `held_at` が付いている。[眠り](sleep.md) の眠りのまま (起きたタブは印が外れるので対象外) |
| タブの本来の口座に、逃げ先 (`fallback`) がある | タブの定義の `fallback_from` が本来の口座。この口座自身のタブ (`fallback_from` が無いタブ) は、自動では続けません。操作者が [続ける](#続ける) |
| 本来の口座が線を下回っている | [口座の逃げ先](account-fallback.md#移す条件) の線と同じ。5 時間が `at_pct` 未満で、7 日が今日の線未満。線に届いていた窓の `*_resets_at` を過ぎていれば、下回っているものとして数える。口座の行が 1 つも無い時は何も言えないので続けない |
| 本来の口座が先回りの線の手前にある | 本来の口座が先回りの線 (`ahead_pct`) に届いている間は、続けません (続けた直後にまた先回りで移す往復を避けるため)。ただし、この口座が止める線に届いている間は、先回りの線に入っていても、線に届いていなければ戻します (逃げ先の線に届いた時の戻し方と同じ) |

戻す時の判定・区切り・冷え待ちは、[口座の逃げ先の戻し方](account-fallback.md#戻す)と**同じ部品**を使います。止まっているタブは眠って
いるので、区切りにあり、キャッシュは冷えています。固定したタブも、本来の口座が線を下回っていれば同じように戻して続けます
(線に届いている間は、固定していても続けません)。

手順は 2 つです。どちらも、見回り (60 秒ごと) が行います。

1. タブを本来の口座へ戻します。眠っているタブを起こす時に戻す手順 ([眠っているタブ](account-fallback.md#眠っているタブ)) と同じです
2. 続けての連絡を送って `held_at` を消します。連絡は、[操作者が続ける時](#続ける) と同じ封筒と同じ口で、口座の欄だけが本来の口座です

```
Sent by the client (the operator did not type this):
<account-hold phase="continue" account="work">
止めていたタブを続けます。止める前の作業を続けてください
</account-hold>
```

```
account hold: resumed on work session=ses_0123456789ab from=personal
```

- 本来の口座もまだ線に届いている間は、何もしません。タブは止まったままで、操作者が「全部続ける」を押せば、この口座で続けます
  (この口座が線を下回っている時だけ)
- この口座だけが空いても、本来の口座が線に届いていれば何もしません
- 戻せなかった時 (タブが他の処理の最中・移した先で会話を開けなかった) は、タブも `held_at` もそのままで、次の見回りでもう一度
  試します
- 戻せたのに連絡が届かなかった時は、`held_at` を残します。次の見回りは、タブを戻し直さずに連絡だけをもう一度送ります

## 動かない時

| 見えること | 原因 |
|---|---|
| 止まらない | 口座に `hold` が無い / 警告の出た `hold` / `config.json` を手で書き換えた後に backend を再起動していない / `rate-limits.jsonl` にその口座の行が無い / 今日の曜日に 7 日の線が無く、`five_hour_at_pct` も無い / タブが固定されている / 逃げ先で動いているタブで、本来の口座が線に届いていない (戻される) |
| `account hold: waits ... reasons=` が出続ける | 区切りに当たっていない。理由は [口座の逃げ先](account-fallback.md#移す条件) の表の通り。`turn_open` なら、タブには 1 回だけ区切りを頼んでいる |
| `account hold: not now ... reasons=` が出る | 区切りを読んだ後に、眠らせる直前の確かめで当たった。次の回にもう一度試す |
| 逃げ先から来たタブが、本来の口座が空いても止まったまま | 本来の口座の使用率の行が、まだ線 (先回りの線を含む) 以上 / 本来の口座の行が無い / 本来の口座の `fallback` を設定から消した / タブが他の処理の最中 / 戻した先でタブの連絡が届いていない (`held_at` が残る。次の回に連絡だけ送る) |
| 「全部続ける」が押せない | 使用率がまだ線 (7 日は今日の線、5 時間は `five_hour_at_pct`) 以上 |
| 続けたのにタブが動かない | `failed` に入っている (連絡が届いていない)。もう一度押す |
